## Default Permission

Indoor bike link: ask for Bluetooth permission, scan, connect, disconnect, read the latest measurements.

#### This default permission set includes the following:

- `allow-ensure-permissions`
- `allow-scan`
- `allow-connect`
- `allow-disconnect`
- `allow-read`
