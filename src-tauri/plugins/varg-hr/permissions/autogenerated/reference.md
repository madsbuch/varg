## Default Permission

Heart-rate strap link: Bluetooth permission, scan, connect, disconnect, read measurements, and the workout's background service.

#### This default permission set includes the following:

- `allow-ensure-permissions`
- `allow-scan`
- `allow-connect`
- `allow-disconnect`
- `allow-read`
- `allow-start-service`
- `allow-workout`
- `allow-stop-service`
